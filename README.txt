# 英単語トレーナー（ターゲット1400）

## 機能
- 週間学習計画とチェックリスト
- 達成率・曜日ごとの進捗表示
- 学習メモ
- 学習タイマー
- 自分で登録する単語クイズ（覚えた／要復習）
- JSON形式のバックアップ・復元
- PWA対応（HTTPSで公開するとホーム画面に追加可能）

## iPhoneのホーム画面に追加する方法
このアプリはファイルを開くだけでは、iPhoneのホーム画面アプリとして完全にはインストールできません。HTTPSのWebサイトとして公開する必要があります。

### GitHub Pagesで公開する例
1. GitHubにログインし、新しいリポジトリを作成する（公開設定）。
2. `index.html`、`manifest.json`、`sw.js`、`icon.svg` をリポジトリのルートにアップロードする。
3. リポジトリの Settings → Pages → Deploy from a branch を選び、`main` と `/(root)` を指定して保存する。
4. 公開された `https://ユーザー名.github.io/リポジトリ名/` のURLをiPhoneのSafariで開く。
5. 共有ボタン →「ホーム画面に追加」→「追加」。
6. ホーム画面のアイコンから開く。

## 保存について
学習記録は端末のブラウザ内（localStorage）に保存されます。同じ端末・同じブラウザで使ってください。ブラウザのデータを消すと記録が消えることがあるため、設定画面からバックアップを保存してください。クラウド同期はありません。

## 学習計画について
最初の1週間の番号は例として設定しています。学校の定期テスト範囲が指定されている場合は、学校の範囲を優先してください。単語帳の語彙データは著作権のため同梱していません。クイズ機能に自分で単語と意味を入力できます。
